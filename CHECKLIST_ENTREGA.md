# Checklist de entrega da APO

## Etapa 1 — Análise (0,5 ponto)

- [ ] Conferir o PDF `Etapa_1_Analise_Gerenciador_Logistico.pdf`.
- [ ] Preencher/identificar a capa com seus dados, se necessário.
- [ ] Entregar o PDF no ambiente virtual conforme orientação do tutor.

## Etapa 2 — Implementação (1,5 ponto)

- [ ] Instalar o XAMPP.
- [ ] Iniciar Apache e MySQL.
- [ ] Copiar a pasta `gerenciador-logistico` para `C:\xampp\htdocs\`.
- [ ] Importar `database.sql` pelo phpMyAdmin.
- [ ] Conferir `config/config.php` (banco, usuário, senha e BASE_URL).
- [ ] Abrir `http://localhost/gerenciador-logistico/`.
- [ ] Testar os cadastros e edição/exclusão de produtos.
- [ ] Testar os endereços de origem e destino.
- [ ] Testar o cadastro de transportador.
- [ ] Gerar um frete com mais de um produto.
- [ ] Consultar o frete e exportar o relatório CSV por data.
- [ ] Criar repositório público no GitHub.
- [ ] Enviar os arquivos do projeto ao GitHub.
- [ ] Conferir se `README.md` explica objetivo, tecnologias e instalação.
- [ ] Executar os casos de `PLANO_TESTES.md` no XAMPP e registrar os resultados.
- [ ] Entregar o link público do GitHub no ambiente virtual.
- [ ] Conferir o repositório em janela anônima para confirmar que está público.

## Etapa 3 — Vídeo (1,0 ponto)

- [ ] Preparar o roteiro em `ROTEIRO_VIDEO.md`.
- [ ] Aparecer no início e falar nome, RA, curso, polo e que é aluno(a) da UNIPAR EAD.
- [ ] Demonstrar o preenchimento de pelo menos um cadastro.
- [ ] Gerar um frete.
- [ ] Comparar as telas com o modelo da Etapa 1.
- [ ] Mostrar um pouco do código e explicar onde estão as funções.
- [ ] Manter o vídeo entre 5 e 10 minutos.
- [ ] Publicar no YouTube como **Não listado**.
- [ ] Entregar o link do vídeo no ambiente virtual.

## Observações

- Não entregue o link do GitHub antes de confirmar que o repositório está público.
- Não grave a demonstração antes de testar localmente todos os caminhos que pretende mostrar.
- A APO exige o vídeo com sua apresentação pessoal; não substitua essa parte por uma gravação apenas da tela.
